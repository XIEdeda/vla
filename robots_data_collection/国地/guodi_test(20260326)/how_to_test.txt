1. 探活与获取设备信息（GET_INFO）
作用：验证连接并获取机器人信息（含相机配置）
{"cmd": "GET_INFO", "mid": 1}

{"cmd": "GET_AGENT_ID", "mid": 17, "data": {"agent_id": "1"}}


2. 启动数据采集（START_TELEMETRY）
作用：开始采集双臂关节数据和相机数据并落盘
{"cmd": "START_TELEMETRY", "mid": 2, "data": {"data_folder": "agent_id/task_id/2"}}
相对路径
{"cmd": "START_TELEMETRY", "mid": 2, "data": {}}
不输入路径
{"cmd": "START_TELEMETRY", "mid": 2, "data": {"data_folder": "/mnt/guodi_dataset/1"}}绝对路径
{"cmd": "START_TELEMETRY", "mid": 2, "data": {"data_folder":"1"}}
表示落在/mnt/guodi_dataset这个默认地址下然后文件夹命名为1

3. 停止数据采集（STOP_TELEMETRY）
作用：结束采集并保存数据（生成 H5 文件、视频等）
{"cmd": "STOP_TELEMETRY", "mid": 3}

{"cmd": "STOP_AND_SUB", "mid": 19}


4. 数据后处理（DATA_POSTPROCESS）
作用：将临时格式数据转换为统一格式，已是落盘格式，直接回应正确
{"cmd": "DATA_POSTPROCESS", "mid": 4, "data": {}}
{"cmd": "DATA_POSTPROCESS", "mid": 4, "data": {"data_folder": "/mnt/guodi_dataset"}}

5. 启动相机预览（START_PREVIEW）
作用：开启指定相机的实时预览（推送帧数据）
{"cmd": "START_PREVIEW", "mid": 5, "data": {"camera_names": ["head", "hand_right","hand_left"]}}
{"cmd": "START_PREVIEW", "mid": 6, "data": {"camera_names": ["head"]}}
{"cmd": "START_PREVIEW", "mid": 6, "data": {"camera_names": ["hand_right"]}}

6. 停止相机预览（STOP_PREVIEW）
作用：关闭预览并释放相机资源
{"cmd": "STOP_PREVIEW", "mid":7 }

7. 恢复初始状态（RECOVER）
作用：关闭所有采集 / 预览，释放所有资源（紧急重置）
{"cmd": "RECOVER", "mid": 8}

"START_PREVIEW"->"STOP_PREVIEW"->"START_TELEMETRY"->"STOP_TELEMETRY"->"DATA_POSTPROCESS"->"RECOVER"
然后之后就是循环"START_TELEMETRY"->"STOP_TELEMETRY"->"DATA_POSTPROCESS"->"RECOVER"

    连接 WebSocket：
